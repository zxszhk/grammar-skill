# grammar

Codex skill distilled from *英语魔法师之语法俱乐部* by 旋元佑.

## Install

After this repository is on GitHub, install it from another computer with the Codex skill installer:

```powershell
python "$env:USERPROFILE\.codex\skills\.system\skill-installer\scripts\install-skill-from-github.py" --url https://github.com/<your-user>/grammar-skill
```

Then restart Codex so the new skill is loaded.

## Use

Ask Codex to use `grammar` when you want sentence-pattern analysis, complements, clauses, non-finite clauses, tense/aspect, articles, mood, or inversion.
