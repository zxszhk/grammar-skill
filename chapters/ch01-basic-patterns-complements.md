# Chapter 1: 基本句型及补语

## Core Idea
英语简单句的核心不是规则名称，而是动词性质。动词如果本身没有叙述能力，就需要补语补足意义。

## Frameworks Introduced
- **五种基本句型**: S+V, S+V+O, S+V+C, S+V+O+O, S+V+O+C。
  - When to use: 分析任何简单句的骨架。
  - How: 先找主语和动词，再问动词是否需要对象、补语或双宾语。
- **补语测试**: O 与 C 之间能放入 be 且意思成立，就是宾语补语。
  - When to use: 分辨 S+V+O+C 与 S+V+O+O。
  - How: 把宾语和后项抽出来，改成 O is C。

## Key Concepts
- **连缀动词**: 可解释成“是/成为/显得/保持”的动词。
- **主语补语**: 说明主语是什么或怎么样。
- **宾语补语**: 说明宾语是什么或怎么样。
- **双宾语**: 两个名词都受动词支配，但彼此不相等。

## Mental Models
Use “是” as the hidden wire: 能用“是”连接的后项多半是补语。

## Anti-patterns
- **只背不完全动词名称**: 标签不能解释为什么句子缺项。
- **把两个名词都看成补语**: 先检查二者是否相等。

## Worked Example
看到 `made him a leader`，不要先背 make 的用法。取出 `him` 和 `a leader`，改成 `he was a leader`，意思成立，所以 `a leader` 是宾语补语。看到 `gave him a book`，`he was a book` 不成立，所以是双宾语。

## Key Takeaways
1. 补语的本质是补足“是”的叙述。
2. be 后没有补语时，be 不是连缀动词，而是存在意义。
3. 句型分析先看语义关系，再看表面词序。
