# Chapter 14: 关系从句

## Core Idea
关系从句来自两个句子的交集。把重复元素改成关系词，再附到先行词后面作形容词。

## Frameworks Introduced
- **交集点模型**:
  - When to use: 合并两个句子为关系从句。
  - How: 找两个句子的重复名词，把从句中的重复点改为 who/which/that/where 等。
- **限定与补充说明的判断顺序**:
  - When to use: 判断关系从句是否参与限定先行词的范围。
  - How: 先用交集点模型还原来源句，确认先行词、重复项以及关系词在从句中的成分；再看先行词脱离从句后是否已经指向明确。若从句负责辨认或缩小先行词范围，就是限定用法；若先行词已经明确，从句只增加说明，就是补充说明用法。
  - Evidence: 逗号、which、专有名词等可以帮助验证判断，但不能代替上述推导，也不能单凭其中一项直接贴上“非限定”标签。
- **关系代名词省略**:
  - When to use: 关系词在从句中作宾语。
  - How: 宾语关系词可省；主语关系词通常不能直接省。
- **that 的使用**:
  - When to use: 先行词受最高级、序数、only/all/every/no 等强限定。
  - How: that 表示强烈锁定先行词。

## Key Concepts
- **先行词**: 被关系从句修饰的名词。
- **关系代名词**: who, whom, which, that。
- **关系副词**: where, when, why。
- **限定/非限定关系从句**: 是否只是补充说明。

## Mental Models
Relative clauses need overlap: 没有交集，就不要硬写关系从句。

Explain the relationship before naming the category: 先说明关系从句如何形成、修饰谁、是否改变先行词范围，再给“限定／非限定”等分类名称。补充其他语法体系的术语时，明确标为术语对照，不用它替代本体系的推导。

## Anti-patterns
- **省略主语关系词**: 会造成两个限定动词挤在一起。
- **把关系从句当名词从句**: 关系从句修饰名词，不占名词位置。
- **由表面标记直接分类**: 看到逗号或 which 就直接称为“非限定”，会跳过先行词范围与从句功能的判断。

## Worked Example
两个句子 `I need a book` 与 `You recommended it` 有交集 `book/it`。把 it 改成 which 并前移，得到 `the book which you recommended`。which 作宾语，可省为 `the book you recommended`。

## Key Takeaways
1. 关系从句必须有交集点。
2. 宾语关系词可省，主语关系词通常不可省。
3. that 常用于强限定先行词。
4. 先推导关系与功能，再判断限定或补充说明；标点和关系词形式只是证据。
