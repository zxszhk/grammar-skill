# Chapter 22: 倒装句

## Core Idea
倒装是把动词或助动词移到主语前，用来强调、避免歧义、增强清楚性或改善句子衔接。

## Frameworks Introduced
- **比较级倒装**:
  - When to use: than/as 从句里助动词不能省，主语又带长修饰语。
  - How: 把助动词移到主语前，拉近逻辑关系。
- **关系从句倒装**:
  - When to use: 关系词、介系词或补语前置后需要更清楚的结构。
  - How: 调整动词与主语顺序。
- **假设语气倒装**:
  - When to use: 省略 if 的 were/had/should 条件句。
  - How: 把 were/had/should 放到主语前。
- **否定副词倒装**:
  - When to use: never, seldom, hardly, only then 等放句首强调。
  - How: 后面用助动词倒装。

## Key Concepts
- **修辞倒装**: 服务表达效果的倒装。
- **助动词前置**: 倒装的常见形式。
- **there 结构**: 主语后置，动词与后方逻辑主语一致。

## Mental Models
Invert when normal order hides the relation: 正常语序让关系变远或变模糊时，倒装可修复。

## Anti-patterns
- **为高级而倒装**: 没有强调或清楚性需求时会显得做作。
- **否定副词句首却不倒装**: 正式英语中常需要助动词倒装。

## Worked Example
比较句中若 than 后的主语带很长关系从句，助动词留在句尾会太远。把助动词放到主语前，可让读者立刻看出比较的是两个主语的动作，而不是误读为宾语。

## Key Takeaways
1. 倒装的价值是强调、清楚和衔接。
2. 比较结构和否定副词最常见。
3. 假设语气可用倒装省略 if。
