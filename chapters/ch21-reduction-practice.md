# Chapter 21: 简化从句练习

## Core Idea
简化从句的练习重点是 sentence combining：把多个简单句合成清楚、精简、无歧义的复杂句。

## Frameworks Introduced
- **组合前先找关系**:
  - When to use: 多句合并。
  - How: 判断是同位、因果、时间、条件、让步、修饰还是对等。
- **歧义排除**:
  - When to use: which/that/分词短语可能指向多个对象。
  - How: 改用名词从句、名词化、介系词短语或重新排列。
- **名词化替代**:
  - When to use: 整个事实作主语/宾语时，关系从句会歧义。
  - How: 用 Ving、failure to、fact that 等结构。

## Key Concepts
- **sentence combining**: 由多个简单句组合成高密度句子。
- **ambiguous 歧义**: 一个句子可被读出两种结构。
- **clarity before brevity**: 清楚先于简短。

## Mental Models
Compression should increase signal: 好的简化让句子更清楚，不只是更短。

## Anti-patterns
- **which 指代不明**: which 可能指前一名词，也可能指整件事。
- **追求高级句型**: 简化不是炫技，服务阅读路径。

## Worked Example
若 `which` 可能同时指代前面的名词和整件事，就不要硬用关系从句。可把整件事名词化，放到主语位置，或用更明确的名词结构表达原因。

## Key Takeaways
1. 先判断句间关系，再选结构。
2. 简化前后都要检查歧义。
3. 名词化是处理整句事实的有效工具。
